One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human:

> I only hum when you walk past — press B4 and the last chocolate is yours, no exact change required.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
